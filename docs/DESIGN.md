## 글자
| 종류 | 크기 |
|---|---|
| 제목 | 28sp |
| 본문 | 20sp |
| 버튼 | 22sp |

- 버튼 높이 64dp
- 모서리 16dp (버튼, 카드)
- 카드 그림자 약하게
- 화면 여백 20dp
