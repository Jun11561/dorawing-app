## 화면별 기능

**처음 실행** — 어르신용 / 보호자용을 고릅니다. 어르신용은 부를 이름을 넣습니다(건너뛰기 가능).

**자가진단** — 15문항에 "아니다 / 가끔 그렇다 / 자주 그렇다"로 답하고 결과를 저장합니다.
- 결과: 30점 중 N점, 정상 범위 또는 전문가 상담 권유
- 6점 이상이면 치매상담콜센터 1899-9988 전화 버튼 표시

**두뇌 훈련** — 4개 영역을 고르고, 한 세트(4~7문제)를 풀면 결과와 함께 기록됩니다.
- 기억력: 카드 짝맞추기, 순서대로 누르기, 있었던 것 고르기
- 주의력 · 계산력 · 언어력: 준비 중
- 1~5단계. 최근 3세트 평균이 80% 이상이면 한 단계 위로, 50% 미만이면 아래로
- 틀리면 정답을 보여 주고 한 번 더 기회, 힌트는 문제당 한 번

**오늘의 건강 카드** — 치매예방수칙 3.3.3, 치매예방운동법 등 공식 자료 기반 카드를 하루 3장 넘겨 봅니다.

**내 기록** — 영역별 정답률 그래프, 이번 주 출석 도장, 마지막 자가진단 결과. 기록이 평소와 달라지면 알림 카드가 뜹니다.

**보호자 연결** — 어르신이 동의하면 6자리 번호(10분, 1회용)가 나오고, 보호자가 입력한 뒤 어르신이 승인하면 연결됩니다. 보호자는 최대 2명, 양쪽 모두 언제든 해제할 수 있습니다. 보호자 폰은 1시간마다 새 변화 알림을 확인합니다.

**설정** — 음성 안내 켜기/끄기, 이름 바꾸기, 보호자 연결. 모든 화면에서 "듣기" 버튼으로 안내를 다시 들을 수 있습니다.

## 실행 방법
1. Android Studio에서 이 폴더를 연다
2. Gradle Sync가 끝나면 에뮬레이터나 폰을 골라 Run
3. 명령줄: `gradlew assembleDebug` (빌드), `gradlew testDebugUnitTest` (단위 테스트)

디버그 빌드에서는 홈 화면 맨 아래 "디버그 메뉴"로 가상 기록을 넣거나 게임을 바로 열 수 있습니다.

### 보호자 연결 확인 (폰 2대)
1. `app/google-services.json`을 넣고, `firestore.rules`를 Firebase 콘솔의 Firestore 규칙에 붙여 넣은 뒤 두 폰에 설치
2. 어르신 폰: 설정 > 보호자 연결 > 어르신용 > 동의 > 6자리 번호 확인
3. 보호자 폰: 처음 실행에서 보호자용 > 번호와 이름, 어르신 호칭 입력
4. 어르신 폰에서 연결하기 > 두뇌 훈련 1세트 → 보호자 화면에 정답률과 출석이 보이면 성공
