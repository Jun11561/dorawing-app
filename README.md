# 두로잉: 오늘의 기억을 그리다

65세 이상 어르신을 위한 치매 예방 안드로이드 앱입니다.
자가진단(KDSQ-C 방식)으로 내 상태를 살펴보고, 두뇌 훈련 게임으로 매일 기억력, 계산력, 주의력, 언어력을 연습합니다.
기록이 평소와 달라지면 알려 주고, 원하면 보호자와 결과를 나눌 수 있습니다.

## 기능
- **첫 실행**: "이 폰을 누가 쓰시나요"에서 어르신용과 보호자용을 고릅니다. 어르신용은 부를 이름을 넣습니다(건너뛰기 가능).
- **자가진단**: KDSQ-C 방식 15문항에 답하고, 답을 확인한 뒤 결과를 저장합니다. 결과는 "30점 중 N점"과 함께 정상 범위 또는 전문가 상담 권유로 보이고, 6점 이상이면 치매상담콜센터 1899-9988 전화 버튼이 나옵니다. 선별 참고용이며 의료 진단이 아닙니다.
- **오늘의 건강 카드**: 공식 자료를 바탕으로 한 카드를 하루 3장 넘겨 봅니다. "자세히 보기"로 공식 사이트나 영상을 엽니다.
- **내 기록**: 영역별 정답률 그래프(가장 낮은 영역이 다른 영역보다 10%p 이상 낮으면 강조), 이번 주 출석 도장, 마지막 자가진단 결과를 보여 줍니다. 기록이 평소와 달라지면 알림 카드로 자가진단을 권합니다.
- **설정**: 음성 안내 켜기와 끄기, 이름 바꾸기, 보호자 연결을 엽니다. 모든 화면에서 듣기 버튼으로 안내를 다시 들을 수 있습니다.
- **보호자 연결과 알림**: 어르신이 동의하면 6자리 연결 번호(10분 동안, 한 번만 사용)가 나오고, 보호자가 번호를 넣은 뒤 어르신이 승인하면 연결됩니다(최대 2명, 양쪽 모두 언제든 해제). 보호자 화면에는 변화 알림, 이번 주 출석, 영역별 정답률과 단계, 자가진단 결과가 보이고, 보호자 폰은 1시간마다 확인해 새 변화 알림을 알려 줍니다.

## 실행 방법
1. Android Studio에서 이 폴더를 연다
2. Gradle Sync가 끝나면 에뮬레이터나 폰을 골라 Run
3. 명령줄: `gradlew assembleDebug` (빌드), `gradlew testDebugUnitTest` (단위 테스트)

디버그 빌드의 홈 화면 맨 아래 "디버그 메뉴"에서 가상 기록을 넣거나 게임 화면을 바로 열 수 있습니다.

## 보호자 연결 확인 (폰 2대)
`app/google-services.json`을 넣고 `firestore.rules`를 Firebase 콘솔 Firestore 규칙에 붙여 넣은 뒤 두 폰에 설치합니다.
어르신 폰: 설정 > 보호자 연결 > 어르신용 > 동의 > 6자리 연결 번호. 보호자 폰: 처음 실행에서 보호자용 > 연결 번호와 이름, 어르신 호칭 입력.
어르신 폰에서 연결하기를 누르고 두뇌 훈련을 1세트 하면 보호자 화면에 정답률과 출석이 보입니다.
